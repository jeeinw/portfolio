## /workbench · 이직 준비 작업대

`workbench/index.html` 단일 파일 웹앱. 배포 후 `jeeinsportfolio.space/workbench/`에서 열립니다 (검색 노출 차단 `noindex`).

- 대시보드: CFA L3 결과 D-day, 진행 중 지원, 연속 연습일, 포지셔닝 위반 일괄 점검, 활동 히트맵
- 경험 뱅크: 상황/접근/결과 + 역할 범위 + 근거, 버전 저장·비교·복원, 드래프트로 보내기
- 문장 다듬기: 자소서·경력기술서·이력서 문장 버전 관리, 실시간 규칙 점검(금지 주장·미검증 수치·상투 어미·톤 기울기), AI 첨삭(선택)
- 지원 트래커: 칸반/표, JD 키워드 추출 → 매칭 경험·갭, 서브도메인·브랜치·타임라인
- 포지셔닝 연습: 면접 Q&A 타이머 드릴(자기 점검·점수·AI 피드백), 피치 타이머
- 연습 기록 / 규칙·설정: 사실 프로필, 검증된 수치, 금지 표현 편집, JSON·Markdown 백업

데이터는 브라우저 localStorage에만 저장됩니다. AI 첨삭은 본인 Anthropic API 키를 설정에 넣었을 때만 동작하며 키는 백업에서 제외됩니다.
